display property
display: inline/block/inline-block/none
inline - takes only the space required by the element. (no margin/padding) (ex. span, button ,input, a)
block - takes full space available in width (ex. div, h1,)
inline-block - similar to inline but we can set margin & padding
none - to remove element from document flow 
whenever blocks are set to display inline then the margin is only applied on the right and left
margin on the upper and the lower side is cancelled

flexbox
flex items try to take up as little horizontal space as possible
when you apply it to a parent element all of its direct children become flex items
and that flex display is applied to the flex items directly
if written in the body tag then the flex works only on tags mentioned in the body tag
to make display flex work in a particular div use display flex separatly in that div 
(in short -- jis tag ki styling mai display flex hoga it will work only on those items who has parent as the
display flex element)

if an element is fixed then the elements which are in it also become fixed
